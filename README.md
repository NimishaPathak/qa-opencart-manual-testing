## Project Overview

This project covers end-to-end manual testing of the OpenCart e-commerce web application. Testing was performed across 11 functional modules including user authentication, product browsing, shopping cart, and the complete checkout flow. The objective was to validate core business workflows, identify defects, and ensure the application delivers a reliable shopping experience.
